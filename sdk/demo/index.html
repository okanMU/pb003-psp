🚀 PSPay SDK Demo

Stripe-like Payment Integration

Kullanım:

1. Tutarı girin ve "Ödeme Oluştur" butonuna tıklayın
2. Açılan modal'da banka bilgileri gösterilecek
3. Real-time olarak ödeme durumu güncellenecek
4. Admin panelden ödemeyi onaylayın/reddedin

Code Example:

const pspay = new PSPay({
  apiKey: 'pk_test_demo_platform'
});

const payment = await pspay.createPayment({
  amount: 1500,
  customer: {
    email: 'customer@example.com',
    phone: '+905551234567'
  }
});

pspay.showWidget(payment.id);
